# PrimeTurf Logo Asset Package

## Brand Colors
- **Green**: #1A5A28 (Forest Green)
- **Gold**: #B8902A (Warm Gold)

## Files

### Main Logos
| File | Description | Recommended Use |
|------|-------------|-----------------|
| `primeturf-full-logo.png` | PT monogram + PRIMETURF wordmark, transparent bg | General use, print, documents |
| `primeturf-header-logo.png` | Same as above, optimized width (800px) | Website headers, navigation bars |
| `pt-monogram.png` | PT initials only, transparent bg | App icons, stamps, embossed use |
| `primeturf-wordmark.png` | PRIMETURF text only, transparent bg | Text-heavy layouts, footers |
| `primeturf-horizontal-logo.png` | Monogram + wordmark side-by-side | Email signatures, banners |

| File | Size | Use |

## Usage Notes
- All PNGs use transparent backgrounds (except `social-profile.png` which has a white background for social platforms)
- Minimum clear space: equal to the height of the "P" letterform on all sides
- Do not stretch, recolor, or add effects to the logo
- For dark backgrounds, use the standard logo as-is (colors remain legible)
