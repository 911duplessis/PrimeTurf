# PrimeTurf Contact Form Specification

## Form: Request a Quote

### Fields

| Field | Label | Type | Required | Notes |
|-------|-------|------|----------|-------|
| first_name | First Name | Text input | Yes | |
| last_name | Last Name | Text input | Yes | |
| email | Email | Email input | Yes | Validate email format |
| phone | WhatsApp / Phone | Phone input | Yes | Accept SA mobile format |
| suburb | Suburb / Area | Text input | Yes | Free text — allow any location |
| service_interest | Service Interest | Dropdown | Yes | See options below |
| project_size | Approximate Project Size | Dropdown | No | Optional — see options below |
| message | Message | Textarea | No | Free text |

### Service Interest Options

1. Premium Artificial Turf
2. Residential Turf Installation
3. Commercial Turf Installation
4. Estate Installation
5. Putting Green
6. Pet-Friendly Turf
7. Pool Surround / Entertainment Area
8. Outdoor Transformation
9. Maintenance & Restoration
10. Other

### Approximate Project Size Options (Optional)

1. Under 50m²
2. 50m² – 100m²
3. 100m² – 200m²
4. 200m² – 500m²
5. Over 500m²
6. Not sure yet

### Submission Behaviour

- On submit: Show a professional confirmation message
- Confirmation message: "Thank you for your enquiry. PrimeTurf will respond within 2 hours during business hours. For immediate assistance, WhatsApp us at 076 804 8868."
- Form submissions must be delivered to the site owner
- **FLAG FOR VERIFICATION**: Confirm that Wix Forms notification email is set to leon@primeturf.co.za in the Wix dashboard (Settings → Notifications → Form Submissions)

### Form Placement

- Primary: /contact page (replace or upgrade existing form)
- Secondary: Embedded CTA section on each location page linking to /contact
- Do NOT place full forms on every location page — link to /contact instead

### Design Notes

- Match existing Wix site premium styling
- Deep Forest / Harvest Gold / Warm Ivory colour palette
- Clean, minimal layout — no unnecessary decorative elements
- Clear field labels, adequate spacing
- Mobile-responsive (single column on mobile)
