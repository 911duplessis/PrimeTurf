## Key Principles

1. **Maximum 2-3 clicks** to any location page from homepage
2. **Do NOT crowd the nav** — Service Areas dropdown groups locations cleanly
3. Existing pages (Johannesburg, Sandton, Hyde Park, Edenvale) remain accessible
4. Service Areas landing page provides full discoverability for all locations
5. Footer should also link to all major location pages for SEO crawl depth
