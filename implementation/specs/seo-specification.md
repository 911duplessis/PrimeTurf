# PrimeTurf SEO Specification — All Location Pages

## SEO Standards (Apply to Every Page)

- One H1 per page (the page title)
- H2/H3 hierarchy for sections and subsections
- Natural location references — no keyword stuffing
- Internal links to Services, Portfolio, Contact, and related Service Areas
- Image alt text on all images
- CTA linking to quote/contact journey
- Canonical URL pointing to the page's own URL

## Internal Linking Strategy

Every location page should link to:
- Homepage (/)
- Services page (/services)
- Portfolio page (/portfolio)
- Contact/Quote page (/contact)
- Service Areas landing (/service-areas)
- 2-3 geographically adjacent location pages

The Service Areas landing page links to ALL location pages.

Footer should include links to major service area pages for crawl depth.

---

## Image Alt Text Convention

Format: `[Description] - PrimeTurf artificial turf installation in [Location]`

Examples:
- "Residential garden transformation - PrimeTurf artificial turf installation in Pretoria East"
- "Pool surround turf - PrimeTurf artificial turf installation in Waterkloof"
- "Estate lawn replacement - PrimeTurf artificial turf installation in Silver Lakes"
