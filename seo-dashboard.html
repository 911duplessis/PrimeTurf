Connect your live data in ~10 minutes

GA4 and Google Search Console cannot be embedded directly into a webpage — they require you to be signed in. The solution is Google Looker Studio: a free Google tool that connects to both GA4 and GSC, builds a live dashboard, and gives you a public embed URL you paste below. Once connected, this page shows real-time metrics automatically.

Step 1 of 3 · Create Report

Set up Looker Studio (free)

  1. Go to lookerstudio.google.com — sign in with the same Google account that owns GA4 & GSC.
  2. Click Create → Report. When prompted to add a data source, click Google Analytics.
  3. Select account PrimeTurf → property primeturf.co.za (GA4) → click Add → Add to Report.
  4. Now click Add data (top menu) → select Search Console → choose primeturf.co.za + Web → click Add.
  5. Build your scorecards: Clicks, Impressions, CTR, Avg. Position (from GSC) + Sessions, Conversions (from GA4). Use charts for time trends.
Step 2 of 3 · Publish & Step 3 · Paste URL

Make it public and embed

  1. In Looker Studio, click the Share button (top right) → Manage access.
  2. Change access to "Anyone with the link — Viewer". Click Done.
  3. Click File → Embed report. Copy the iframe src URL (starts with https://lookerstudio.google.com/embed/reporting/...).
  4. Paste that URL into the field below and click Activate. Your live dashboard will appear instantly.
