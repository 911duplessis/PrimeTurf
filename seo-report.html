Setup Guide — 10 minutes
Step 1 — Create Report
  1. Go to lookerstudio.google.com and sign in
  2. Click Create → Report
  3. Add data source: Google Analytics → select your GA4 property
  4. Click Add data again → Search Console → primeturf.co.za + Web
  5. Add scorecards: Clicks, Impressions, CTR, Avg. Position (from GSC) + Sessions, Conversions, WhatsApp clicks (from GA4)
Step 2 — Publish & Embed
  1. Click Share → Manage access
  2. Set to "Anyone with the link — Viewer" → Done
  3. Click File → Embed report
  4. Copy the src URL from the iframe code
  5. Paste into the field above and click Activate
