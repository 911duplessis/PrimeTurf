Setup Checklist
01
WhatsApp Business App
Download free. Set up your profile: "The Connection Network" as display name. Add your number. Set business category to "Consulting".
02
Quick Replies
Pre-save all auto-reply messages as Quick Replies in WA Business. Trigger keywords: CONNECT, TURF, JOIN, READY, ACTIVE, STAY, OUT, IN.
03
Contact Labels
Create all tags as Labels in WA Business contact manager. Use colors: Gold = PRIORITY, Blue = ACTIVE, Green = REFERRER, Grey = EXPLORER, Red = COLD.
04
Broadcast Lists
Create 3 broadcast lists: PRIORITY, ACTIVE, GENERAL. Populate from labels. PRIORITY list gets opportunities first — 24h before GENERAL.
05
Away Message
Set away message for after hours: "The Connection Network — we'll respond by 9AM. If urgent, send your area + need and we'll match you overnight."
06
Link to Landing Page
Add your landing page URL to WA Business profile. Set the CTA button to "Visit Website". All status posts link back to the funnel page.
